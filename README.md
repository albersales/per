# Parañaque Emergency Ready (PER)

One-tap access to all emergency contacts in Parañaque City.

**Prepared. Educated. Ready.**

## Live App
https://albersales.github.io/per

## Features
- Emergency hotlines (911, EOC, BFP, PNP, HEMS, DRRMO)
- Personal emergency profile
- 72-hour Go Bag checklist
- Works 100% offline
